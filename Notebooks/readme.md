# Notebooks

- `crawl_more_data.ipynb` — OpenAlex crawler (multi-term search → flattened CSV).
- `data_preprocessing.ipynb` — cleaning, EDA and feature engineering.
- `metric_definitions.ipynb` — documents and sanity-checks the analytical
  metrics the dashboard uses (topic buckets, Gini, Lorenz, entropy, CAGR,
  pressure index), reusing the same code in `../src/`.
